## 简体中文

NoxShare 1.0.7：支持简体中文和 English 的 Android 局域网共享工具。制作：**@NoxLeo**。

### 下载和安装

- **NoxShare-1.0.7.apk**：手机安装包，支持 Android 8.0 及以上。
- **NoxShare-1.0.7-source.zip**：完整源码，含中英文 README、使用说明和构建指南。
- **SHA256SUMS.txt**：安装包及源码包的 SHA-256 校验值。

下载 APK 后在手机安装，连接同一 Wi-Fi，点击「开启共享」，其他设备使用浏览器打开显示的地址。此 APK 使用与之前测试包相同的开发签名，可覆盖同签名版本安装。

### 功能

- 聊天式文件、图片、视频和文字互传，网页支持拖拽上传。
- 图片放大、视频播放和拖动进度，默认应用打开文件。
- 聊天页长按文件删除，文字/链接长按复制，网址可点击。
- 多选、搜索、已发送/已接收、清空及 ZIP 下载。
- 网络信息、安装授权与通知设置，可选关闭共享后清理内容。
- 设置中选择跟随系统、简体中文或 English，网页可独立选择。

[中文使用说明](https://github.com/NoxLeo725/NoxShare/blob/main/docs/USAGE.zh-CN.md)

已通过浏览器功能测试及 Android 15 模拟器测试；尚未进行 Android 真机联网验证。

## English

NoxShare 1.0.7 is an Android LAN sharing app with Chinese and English interfaces. Made by **@NoxLeo**.

### Download and install

- **NoxShare-1.0.7.apk**: Android installer, for Android 8.0 and later.
- **NoxShare-1.0.7-source.zip**: complete source with bilingual READMEs, user guides and build instructions.
- **SHA256SUMS.txt**: SHA-256 checksums for the APK and source archive.

Install the APK on your phone, connect devices to the same Wi-Fi, tap **Start sharing**, and open the displayed address in another device's browser. This development-signed APK retains the previous test build's signing certificate and can update compatible installations.

### Features

- Chat-style file, image, video and message sharing, with browser drag-and-drop uploads.
- Image zoom, video playback/seeking, and default-app file opening.
- Long-press chat files to remove; long-press text/links to copy; clickable URLs.
- Search, multiple selection, sent/received filters, cleanup and ZIP downloads.
- Network details, installation/notification settings and optional cleanup when sharing stops.
- System, Chinese or English language selection, independent for each browser.

[English user guide](https://github.com/NoxLeo725/NoxShare/blob/main/docs/USAGE.en.md)

Verified with browser tests and an Android 15 emulator. Physical-device networking has not yet been verified.
